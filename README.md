# NABU Project

## Overview

The NABU Project is a research initiative led by **Turaath Tech** that investigates the online trade in Iraqi cultural goods using computational methods. The project focuses on identifying patterns in the circulation of potentially illicit or unprovenanced artifacts across digital platforms.

By combining open data collection with quantitative and qualitative  analysis, NABU contributes to ongoing efforts to better understand and ultimately disrupt the trafficking of cultural heritage.

---

## Research Objectives

- Document the presence of Iraqi cultural goods on online marketplaces
- Identify patterns in listing behavior, object types, and pricing
- Detect indicators of potentially illicit or unprovenanced material
- Contribute reproducible, transparent methodologies for researchers and policymakers

---

## Methodology

The NABU Project applies established computational research methods, including:

- Web scraping and data collection from public, online platforms
- Quantitative analysis of listing trends and object characteristics
- Comparative analysis of object images
- Pattern detection for identifying suspicious or high-risk activity

All methods are designed to be transparent, reproducible, and adaptable to other datasets and regions.

## Data Access and Ethics

Due to the sensitive nature of cultural heritage trafficking research:

- Raw datasets are not publicly shared where they may contain sensitive or identifying information
- This repository includes:
  - Restricted datasets (with personal identifying information and URLs obscured, redacted, or pseudonimised)
  - Code required to reproduce data collection and analysis
  - Public research outputs

The project adheres to ethical research standards, including:
- Avoiding harm to individuals or communities
- Preventing misuse of data
- Respecting cultural property and legal frameworks

For collaborations or access requests to the unrestricted dataset, please contact the project team.

## Reproducibility

This repository is designed to support fully reproducible research using publicly available data. Because the NABU Project collects and analyses sensitive marketplace data, only sanitised datasets are included here. Workflows for additional sources follow the same structure.

### 1. Set up a Python environment
We recommend using a virtual environment to avoid dependency conflicts:

```bash
python -m venv nabu-env
# macOS / Linux
source nabu-env/bin/activate
# Windows
nabu-env\Scripts\activate
```

### 2. Install dependencies
Install all required Python packages:

```bash
pip install -r requirements.txt
```

### 3. Prepare data
- Restricted datasets are included for reproducibility:
  ```
  athar-sale/data/processed/
  ```
- Raw or full datasets are not included due to sensitivity.

### 4. Run notebooks in sequence
Workflows are designed to be run step by step:

1. `AS_data_collection.ipynb` — collect or load data  
2. `AS_analysis.ipynb` — conduct quantitative analysis

### 5. Notes
- Configurable file paths can be set in each notebook to point to different datasets or sources.
- Figures, tables, and networks generated by notebooks are saved in the corresponding `outputs/` folder.
- Using this structure ensures transparency, reproducibility, and clarity for collaborators and other researchers.

### ⚠️ Caution:
This repository contains restricted data without identifying information. Running the data collection code with live platforms may produce sensitive or personal data.
Do NOT commit raw outputs to the public repository. Always use `.gitignore` for `data/raw/` or other sensitive folders.
